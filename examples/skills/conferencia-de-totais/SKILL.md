# Conferência de totais

Conferência rápida, fictícia, usada nos exemplos do Skill Flow.

## Quando usar
Antes de publicar qualquer relatório que traga totais.

## Como conferir
1. Some novamente cada coluna de totais a partir dos dados brutos.
2. Compare o resultado com o que está no relatório.
3. Anote a diferença de cada coluna.

## Tolerância
- Diferença até 0,5%: aceitável; registre.
- Acima de 0,5%: bloqueia a publicação até ser explicada.
