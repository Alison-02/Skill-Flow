Skill Flow
Comece por aqui
Clique ou arraste um item do painel da esquerda (skills, trechos, ferramentas, lógica) para o canvas e ligue as etapas. Ou abra um exemplo para ver como fica.
Os exemplos usam as skills e os bancos da pasta examples/ do repositório. Para vê-los, inicie o servidor a partir da raiz do clone: python app/server.py --data examples/data

Esta ajuda?
Gerar SKILL.md com valores
Os {parâmetros} das instruções saem preenchidos. Os valores calculados aparecem em verde.
Trocar a fonte desta etapa
As conexões, o grupo, o título que você escreveu, a instrução e a prova continuam como estão. Só muda o que o Claude vai ler.
Escolha um item na lista para ver o conteúdo.
Medir a qualidade do fluxo
Mede só o que você registra aqui. Para saber se o fluxo mantém a qualidade, compare execuções conferidas feitas COM e SEM ele; o ideal é refazer uma execução já conferida (mesmo projeto e período).
Categorias das skills
Define em que grupo cada skill aparece no painel da esquerda. Só muda a organização aqui (config.json); a skill continua onde está.
Bancos de dados
Declare cada banco que os fluxos podem consultar: o tipo, como o Claude o acessa na hora de executar e as tabelas com as colunas. O editor nunca se conecta ao banco. Senhas e chaves NÃO ficam aqui: informe só o NOME da variável de ambiente que guarda a chave.
